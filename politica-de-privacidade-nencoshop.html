PRIVACY POLICY - ACHADINHOS TECH SOFTWARE INTEGRATION
Last Updated: July 2026

1. SCOPE AND PURPOSE

This Privacy Policy governs the data processing practices of the internal application "Central_Content_Manager" developed for the business profile @NencoShop ("Achadinhos Tech"). This application operates strictly as a single-user, personal content automation tool under the Pinterest Developer and API Terms of Service.

2. DATA COLLECTION AND MINIMIZATION

In strict compliance with Pinterest Data Privacy rules:

  • The application DOES NOT collect, harvest, scrape, or store any public or non-public data from third-party Pinterest End Users.
  • The application DOES NOT collect or store User passwords, session cookies, or personal identification. All access is handled locally via standard OAuth 2.0 Access Tokens.
  • No personal data or platform insights are combined, shared, or sold to third-party advertising services or external data marketplaces.

3. USE OF DATA

Any data accessed through the Pinterest API (specifically related to the authenticated user's boards and pins under the "org_write" scope) is used exclusively for the automated design generation (via Pillow interface) and internal scheduling of product recommendation content. This integration respects the permissions for boards:read, pins:read, and pins:write.

4. DATA SECURITY

The developer implements industry-standard local security measures to safeguard all API credentials, App Keys, and Access Tokens. No server-side processing or external cloud storage is utilized, eliminating the risk of unauthorized data breaches.
